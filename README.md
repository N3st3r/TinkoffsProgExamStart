# TinkoffsProgExamStart
Экзамен по программированию на стажировку в Т-Банк. Его проходят все разработчики, а также QA, ML и SRE инженеры.  Экзамен содержит 7 задач разной сложности, и 3 часа на решение.  Каждая задача оценивается по 100-бальной шкале.
